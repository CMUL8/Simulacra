# Report craft

You are designing a **long-form HTML report**, not an interactive app.

## Hierarchy
1. Cover (title, one-liner, date/meta)
2. Executive summary (3–5 sentences + KPI strip)
3. Numbered sections driven by the data (risk mix, vendors, themes, evidence)
4. Closing / next steps

## Visual rules
- Document flow: readable measure (~65ch), clear H1/H2, generous section spacing
- Print-friendly: light or dark per brief; avoid sticky app chrome and filter bars
- Evidence callouts cite vendors / scores from `data.json` — never invent
- Charts: simple ranked bars or distribution blocks; no decorative sparklines without meaning
- Typography from the design brief; no emoji; no purple glow; no generic Inter-on-white

## Done when
- Feels like a finished PDF-in-browser report
- Scannable in 30 seconds, readable in 5 minutes
- Empty room → honest empty state
