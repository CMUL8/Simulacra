# One-pager craft

You are designing a **single printable page**, not an app and not a multi-section scroll essay.

Author the one-pager the **user asked for**. Discard Vendor Risk / diligence chrome unless that is the topic.

## Hierarchy
1. Headline + one-liner (from the user goal)
2. 3–5 KPIs only if the data supports real metrics
3. Priority list / evidence strip driven by the topic
4. One short "so what" / next step

## Visual rules
- Fits ~letter/A4 at print scale; avoid multi-page scroll as the design
- Dense but breathable; strong typographic hierarchy
- No tabs, no sticky filters, no app chrome
- Numbers from analytics/data — never invent
- Brief palette + density; no emoji; no purple glow

## Done when
- One screen tells the story for THIS topic
- Print preview still readable
- Empty room → honest empty state on one sheet
